# Fit-free correspondence assessment

Run `smoke.py --output-dir NEW_DIRECTORY` with an installed Super Deli package.
It reuses the preceding replacement audit's invented four-specimen fixture and
then checks invented documentary voucher and haul records. Every file under
`fixture/` is synthetic; none contains real biological specimens or author data.
`plan.json` at this level contains only real source locks and review limitations.
`results/` contains only small public aggregates. Complete real records and
checklists remain local. See `docs/skate-correspondence.md` for the command and
`docs/skate-correspondence-results.md` for unresolved real-data findings.

No fitting or contact is supported by this workflow. Blank output templates
are unpopulated schemas, never accepted as completed correspondence evidence.
