# Empirical benchmark foundation

`profile.json` and `protocol.json` lock the audited author-mirror source and the
non-executable future evaluation plan. `catalog.json` records selection and
applicability limitations. No real source/curated records are bundled.

`fixture/` is an entirely invented 12-row engineering input with ten complete
rows. It is not empirical evidence. `smoke.py` exercises the installed CLI offline;
`download.py` optionally retrieves the exact locked real source into a new local
directory. See `docs/empirical-benchmark-foundation.md` for commands, credits,
source-version limitations and the unresolved biological gates.
