# Amphipod evidence-gate findings

Three previously unresolved specimen/accession links now have corroborating
explicit voucher/COI pairs in the public molecular table. One of the remaining
11 cases instead has a conflicting voucher claim, and seven remain supported
only by the original workbook's stated accession. The prior audit's 162 literal
GenBank links, including six source-cautioned rows, remain unchanged.

| Evidence accounting | Retained result |
| --- | ---: |
| Original trait rows / stated valid COI entries | 1,123 / 173 |
| Unflagged documentary specimen links | 159 |
| Additional explicit-table corroborations | 3 |
| Conflicting voucher claims / accession-only unresolved cases | 1 / 7 |
| Linked raw molecular partitions | 117 |
| One-to-one partition context / split-or-merge context | 74 / 43 |
| Explicitly weaker type-locality / morphology MOTU assignments | 34 / 17 |
| Composite-marker rows in the phylogeny table | 50 |

The 117 rows are documented reference links, not a selected analytical cohort.
No feature/missingness policy was applied to create a benchmark. The operational
PTP/ASAP hypotheses are retained separately from historical MOTUs and accepted
study labels. Different PTP/ASAP label strings alone do not signal disagreement.
The 43 split/merge contexts describe the published partitions, not Super Deli
performance or 43 biological errors.

The main supplement contains 3,326 populated reference records plus more than a
million empty formatting rows. Across the five reference workbooks, 1,049,967
serialized rows include 1,045,251 empty formatting rows. These never become
specimens. The source tables retain duplicate accession keys: 58 in the broad
COI table and four in the focal-complex table. None is silently deduplicated.

The molecular paper reports 3,310 delimitation individuals and 561 phylogeny
MOTUs; the corresponding tables retain 3,326 and 560 data rows. The focal table's
376 data rows match the reported count. These quantities and scopes are recorded
without deleting rows, inventing missing records or declaring their discrepancy
resolved. All row attributes, dates, style/merge metadata and original values
remain available locally.

The [trait paper](https://doi.org/10.1038/s41597-024-03020-w) documents targeted
selection and mixed reference-assignment provenance. The [molecular study](https://doi.org/10.1111/fwb.70000)
uses sequence-based raw delimitations and subsequent taxonomic review. Those
are valuable reference hypotheses, but do not establish independent species
truth for every measured specimen. Composite-marker records and all source
cautions remain explicit; none is repaired from label agreement.

The [catalogue](https://db.subbio.net/) states its records are not public.
Exact locality/date token comparisons remain context, not authoritative survey
identities or evidence of statistical independence. Blank remarks do not prove
DNA validation; absent historical MOTU labels are distinguished from undocumented
assignment basis. No data-dependent cohort or one-specimen-per-site subset was
created, and no sampling assumptions were silently adopted.

The independent audit reconstructs all trait/reference joins, cells and formatting
counts, public inventory checks, PDF/DOCX text derivatives, method-partition
relations and gate reasons without importing the assessment code. The unchanged
prior audit is reproduced byte for byte. Models, defaults, old schemas and
historical p-values remain preserved. Detailed evidence stays local; no author
or custodian was contacted, no private record was accessed and no biological
model was fitted.

A future descriptive concordance study needs a separately frozen target,
raw-feature/missingness policy and sampling interpretation. Independence-dependent
inference additionally needs a documented event/identity crosswalk and a justified
dependence design. Those requirements remain explicit rather than being satisfied
by a locality match or a public DNA accession.
